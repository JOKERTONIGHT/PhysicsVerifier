# 规则目录说明

- `rules_catalog_top_down.json`：自顶向下的物理知识骨架。
- `scenario_cluster_blueprints.json`：Scenario Cluster 配置源。
- `rules_unified_3000.json`：扩展后的统一规则候选库。
- `rules_unified_3000_runtime_backfilled.json`：verifier 当前运行库。
- 其他 JSON 多为历史输入、构建中间产物或实验版本，不能仅凭文件名替换运行库。

规则库结构、规模和维护方式见 [`docs/规则库说明.md`](../docs/规则库说明.md)。
