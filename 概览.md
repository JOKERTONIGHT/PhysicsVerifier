# PhysicsVerifier 概览

> 详细说明见 [`docs/整体结构.md`](整体结构.md)

## 项目定位

对物理竞赛题的模型作答进行规则检查——给定题目及作答，判断是否存在违反物理规则的错误，并给出具体定位与原因。

---

## 全流程逻辑链条

### 离线：规则库建设

```
语义蒸馏
  scripts/generate_experience_rules.py
        │ 输出 distilled_rules JSON（含 rule_id / domain / topic / trigger / check_logic / symbolic_hint）
        ▼
规则库构建
  scripts/manage_rule_library.py build   （内部: rule_framework/builder.py）
        │ 输出 unified_rule_library.json（domain→topic→cluster→rule 树 + 扁平 topic.rules 视图）
        ▼
符号代码翻译（可选）
  scripts/generate_symbolic_checks.py
        │ LLM 生成确定性 Python 函数 → manifest + symbolic/generated_experience_checks.py
        ▼
符号绑定回库（可选）
  scripts/manage_rule_library.py bind-symbolic
        │ 将 manifest 中的 symbolic_binding 写回规则叶子
```

### 在线：样本检查（run_verifier.py）

```
输入样本
  {question, prediction, answer}
        │
        ▼
【1】规则匹配（core/rule_catalog_retrieval.py）
   · 对全库主题打分 → Top-K 主题
   · 对主题内规则打分 → 候选规则集合
        │
        ▼
【2】语义检查（core/semantic_rule_checker.py）
   · 构建 SymbolGraph（公式/符号关系图）
   · 将 SRD（规则定义文本）注入 prompt
   · 调用 LLM → diagnostics 列表
        │
        ▼
【3】符号核查（core/physics_rule_verifier.py）
   · 按 rule_id 查找 generated_experience_checks.py 中的函数
   · 执行确定性检查 → pass / fail / inconclusive
   · 策略合并：fail/inconclusive 保留 diagnostic；全 pass 则抑制
        │
        ▼
输出 JSON
  主结果（diagnostics）+ 符号审计（symbolic_audit）
```

### 离线：测评

```
构建测评集
  scripts/build_physics_eval_sets.py
        │ recall 集（含错误 GT）+ precision 集（正确样本）
        ▼
运行检查
  scripts/run_verifier.py → 预测结果
        ▼
错误级评测                      题目级评测
  evaluate_physics_eval_sets.py    evaluate_question_level_sets.py
        │                                    │
        └──────────────┬─────────────────────┘
                       ▼
              compute_strict_eval_metrics.py
                  Precision / Recall / F1
```
