# 背景信息接入方案

## 目标

保留现有规则库，将题目背景直接接入语义树导航。规则库提供较粗的知识结构，模型在检索过程中根据具体题目完成细化，而不是继续增加更细的静态叶子。

## 各层输入

```text
question + context
  → BackgroundAnalysis + Domain
  → Topic
  → Scenario Cluster

question + context + BackgroundAnalysis + prediction（分字段提供）
  → Rule
  → Semantic Checker
```

- BackgroundAnalysis 包含当前小问、物理对象、过程、条件、待求量、符号与单位、缺失信息和非当前背景。
- `question + context` 决定规则适用范围。
- `prediction` 只用于规则叶子选择和错误证据，不得补造题设。
- 参考答案不进入 verifier。

## 导航原则

- BackgroundAnalysis 与 Domain 在同一次 API 调用中生成，属于 verifier 主流程。
- Domain、Topic 使用稳定 ID，避免名称格式差异导致空结果。
- Topic、Scenario Cluster 使用结构化背景和候选摘要进行选择。
- Scenario Cluster 是硬边界；命中具体 Cluster 后不扫描整个 Topic。
- 通用推理规则只在具体路径没有规则时兜底。
- 词法检索只用于离线诊断，不允许在 API 失败后自动回退。

## 输出要求

- BackgroundAnalysis。
- 选中的 Domain、Topic、Scenario Cluster 和 Rule。
- 各层候选、模型响应、接受项、拒绝项和未返回项。
- API 失败层级、空结果原因和部分完成结果。
- 最终诊断、quote 定位和发布门结果。

## 效果判断

典型样本只用于核对逐层路径和结构错误，不要求命中固定规则。完整测评用于比较规则召回、最终召回率和 FP。只有独立样本上的真实结果能决定哪些叶子需要合并或调整层级。
