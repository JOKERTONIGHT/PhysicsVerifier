# 项目目录与运行边界

## Verifier

远程仓库是 verifier 和规则库的唯一权威来源：

- `core/`
- `catalogs/`
- `rule_framework/`
- `rules/`
- `symbolic/`
- `scripts/run_verifier.py`

本地测评和训练不得在这些路径中加入兼容补丁。需要适配时，应在 `evaluation/` 或 `training/` 中调用公开的 Python/CLI 接口。

## Evaluation

`evaluation/` 保存本地 HiPhO、规模实验、报告和历史生成代码。通用数据构建与 P/R/F1 计算继续复用远程 `scripts/` 中的正式实现。

## Training

`training/` 保存 OpenRLHF、reward server、RL 数据准备和训练文档。旧 slime 路径已经归档，活动代码只保留答案判分所需的最小兼容模块。

## 外部资产

- `data` → slow-share 数据集
- `results` → slow-share 运行结果和 symbolic manifest
- `.venv` → 本机 verifier 环境
- OpenRLHF 环境、模型和 checkpoint → slow-share 或 `/data1`

当前正式规则库为 `catalogs/rules_unified_3000_runtime_backfilled.json`。该库默认使用语义导航；在没有匹配 symbolic manifest 时关闭符号核查。
