# 语义检索实验

## 实验目的

六个典型样本用于检查 `Domain → Topic → Scenario Cluster → Rule` 是否能到达合理规则。它们用于观察路径，不用于计算召回率或 FP。

| ID | 物理背景 | 主要检查点 |
|---|---|---|
| `154795` | 载流导线磁场与磁通积分 | 区分静磁通和电磁感应；题面缺图 |
| `62392` | 带电导体球的静电压力 | 进入静电学并找到表面受力规则 |
| `142854` | 对称直流电路 | 正确处理缺失电路图 |
| `170364` | 变散热功率下的冷却 | 识别热容和温度积分 |
| `167622` | 卫星轨道衰减 | 排除长背景中的非当前电磁机制 |
| `194394` | 黑洞视界附近空间长度 | 区分空间距离、固有时和坐标时 |

## 首轮结果

- 六题均完成 API 调用，但都停在 `semantic_tree_empty`。
- Domain 命中 5 题；Topic、Scenario Cluster 和 Rule 均为空。
- 因为没有到达规则叶子，这一结果不能证明“叶子过细”或规则缺失。

主要原因是 Topic 名称匹配过严、候选提示不足、模型异常响应被当成空结果，以及逐层 trace 不完整。对应代码已经补上稳定 ID、结构化背景、候选提示、JSON 合约重试、空结果复核和完整 trace。

## 旧词法基线说明

旧词法检索曾暴露四类典型问题：

- `154795` 被答案词汇带到流体力学。
- `62392` 的静电规则存在，但 Topic 与门控没有利用导体表面背景。
- `170364` 的冷却积分规则存在，但被错误 Topic 和扁平排序压低。
- `194394` 的 Topic 正确，相关空间距离规则仍被 Top-K 截断。

词法分数只用于定位问题，不能代表正式语义检索效果。

## 流程验收标准

- 所有样本必须保存 BackgroundAnalysis 和逐层候选 trace。
- API 格式错误必须重试或明确报错，不能静默变成空树。
- 结果中必须能看到具体 `retrieved_rules`，或明确的无规则原因。
- 缺图、缺定义和非当前背景必须被明确记录，不能由 prediction 补造。
- 不要求六题命中固定 `rule_id`；规则库叶子过细本身就是待研究问题。
- 样本路径由人工核对；整体效果由独立数据上的全流程召回率和 FP 实验判断。

当前本地真实 API 冒烟运行已经完整走通并输出规则。原始输入和运行结果保存在本地 `data/`、`results/`，不随 Git 提交。
