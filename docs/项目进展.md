## 协作方式

- 个人 fork 负责阶段开发和验证。
- 持续同步 upstream 最新进度。
- 一阶段完成后提交 PR 给学长审核；本轮暂不提交。

## 运行边界

- 本机：代码修改、数据整理、无 API 单元测试和静态检查。
- 服务器：所有 API 训练、语义检索实验和全流程测评。

## 当前确定方向

- 不推翻现有规则库，也不重新生成全部规则。
- 正式规则检索以 API 语义树为准：`Domain → Topic → ScenarioCluster → Rule`。
- Domain、Topic、ScenarioCluster 只读取 `question + context`；Rule 层才单独读取 `prediction`。
- 词法检索只保留为离线诊断，不允许 API 失败后自动回退。
- 后续根据真实逐层结果推进规则库粗放化和动态扩展。
