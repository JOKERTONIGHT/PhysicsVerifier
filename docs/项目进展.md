## 运行边界

- 本机：代码修改、数据整理、无 API 单元测试和静态检查。
- 服务器：所有 API 训练、语义检索实验和全流程测评。
- 当前服务器：`visitor@node13`。
- 仓库路径：`~/huhengyuan/PhysicsVerifier`。
- conda 环境：`physics`。
- 长时间 API 训练和实验默认放入 `tmux` 会话，并同步保存日志。
- `.env` 不随 Git 同步，API 任务运行前必须确认服务器已配置 `OPENAI_API_KEY` 和 API 地址。

## 当前确定方向

- 不推翻现有规则库，也不重新生成全部规则。
- 正式规则检索以 API 语义树为准：`Domain → Topic → ScenarioCluster → Rule`。
- Domain 同步生成 BackgroundAnalysis；Topic、ScenarioCluster 使用题面与该分析，Rule 层才单独读取 `prediction`。
- Domain、Topic 使用稳定 ID；Topic 导航同时使用已有 retrieval hints 和 Cluster 摘要。
- ScenarioCluster 作为硬边界；已有 Cluster 时不做整 Topic 扫描，通用推理只作末级兜底。
- 词法检索只保留为离线诊断，不允许 API 失败后自动回退。
- 后续根据真实逐层结果推进规则库粗放化和动态扩展。
