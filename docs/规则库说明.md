# 规则库说明

## 当前结构

统一规则库的运行结构为：

```text
Domain → Topic → Scenario Cluster → Rule Group → Rule
```

`Rule Group` 是可选内部层。运行时以 Scenario Cluster 为检索边界，不在命中具体 Cluster 后重新扫描整个 Topic。

## 当前规模

- 6 个 Domain。
- 123 个 Topic，其中 93 个包含可执行规则。
- 488 个 Scenario Cluster。
- 4875 条可执行规则。
- 1082 条自顶向下知识规则作为知识参考。

## 主要文件

| 文件 | 作用 |
|---|---|
| `catalogs/rules_catalog_top_down.json` | 物理知识骨架 |
| `catalogs/scenario_cluster_blueprints.json` | Scenario Cluster 的正式配置源 |
| `catalogs/rules_unified_3000.json` | 扩展后的统一规则候选库 |
| `catalogs/rules_unified_3000_runtime_backfilled.json` | verifier 当前运行库 |
| `scripts/build_unified_catalog.py` | 统一规则库构建脚本 |
| `scripts/unified_rules_pipeline.py` | 规则库构建主入口 |

运行库是构建产物，不直接手工修改。新增和修正规则应进入构建输入，再通过统一流水线重建和验证。

## 当前判断

现有规则库已经可用，不需要推翻重建。当前重点是利用题目背景改进树内导航，再根据真实失败路径决定哪些叶子应合并，以及如何支持规则库动态扩展。
